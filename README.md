## 🧑‍💻 About Me

I'm a developer and designer who enjoys building things that live at the intersection of clean code and clean design. Whether it's a polished web app, a quick CLI tool, or a thoughtfully edited photo, I care about the details that make something feel finished.

- 🔭 I work across the stack — **TypeScript / React / Node** on the front, **Python, C#, and .NET** on the back, with a soft spot for **AWS, Azure, and Cloudflare** when it's time to ship.
- 🎨 I split my time between **engineering** and **design** — I'm comfortable in **Figma**, the **Adobe Creative Cloud** suite, and a terminal in equal measure.
- 🌱 I'm always learning. Lately I've been deep in **distributed systems**, **modern React patterns**, and **AI-assisted developer tooling**.
- 🛠️ I like building side projects that scratch a real itch — small, useful things that I'd actually use myself.
- 📫 The best way to reach me is on [LinkedIn](https://linkedin.com/in/aryantayal).
- ⚡ Fun fact: when I'm not coding, you'll probably find me behind a camera or editing in Lightroom.
